## Padrão Atual de Módulos (Backend)

Cada domínio segue a estrutura:
```
{dominio}/
├── controller/   # @RestController — entrada HTTP
├── domain/
│   ├── model/    # @Entity JPA
│   └── dto/      # Records/classes de entrada e saída
├── repository/   # JpaRepository
└── service/      # Lógica de negócio (maioria vazia ainda)
```

**Problema identificado:** Falta camada de mapeamento explícita (model ↔ dto), ausência de exceções customizadas, controllers fazem mais do que deveriam.

## Segurança (Fluxo de Auth)

```
Request → JwtAuthenticationFilter
            ↓ extrai Bearer token
          JwtService.verify()
            ↓ válido
          SecurityContext.setAuthentication()
            ↓
          Controller executa
```

**Refresh Token Flow:**
1. Access token expira (401)
2. Client interceptor detecta 401
3. Coloca requests pendentes numa fila
4. Chama `/auth/refresh` com refreshToken
5. Obtém novo par de tokens
6. Replay das requests da fila

**Token Storage:**
- Access token: memória (AuthContext state)
- Refresh token: localStorage ← **ponto de atenção** (XSS risk)

## Banco de Dados

**Convenções:**
- PKs: `BINARY(16)` (UUID como bytes)
- Timestamps: `DATETIME` (`createdAt`, `updatedAt`)
- Soft delete: coluna `active` (TINYINT)
- Arquivamento: coluna `archivedAt` (patients)

**Relacionamentos principais:**
```
User (1) ←—MapsId—→ (1) Nutritionist
Nutritionist (1) ——→ (N) Patient
Patient (1) ——→ (N) Avaliation
Nutritionist (1) ——→ (N) Subscription
Subscription (1) ——→ (N) Payment
```

## Pontos de Melhoria (alvo da refatoração)

1. **Exception handling centralizado** — pasta `shared/exceptions/` existe mas vazia; precisa de `@ControllerAdvice` global
2. **Services vazios** — patient, nutritionist, avaliation, billing precisam de implementação completa
3. **Mapeamento DTO** — usar MapStruct ou mapeamento explícito nos services
4. **Refresh token no localStorage** — migrar para httpOnly cookie
5. **Testes** — nenhum teste automatizado ainda
6. **RegisterUserController** — vazio, registro não funciona
7. **Nomenclatura** — `avaliation` é "avaliation" em todo o código (não "evaluation"); manter consistência
8. **Billing** — controllers existem mas sem qualquer integração de gateway
